FEATURED OPEN SOURCE / RUSTBGP

bgp-display

BGP Link Manager · Network operations in your terminal.

A Rust terminal application for monitoring and managing BGP sessions across routers from multiple vendors. Inspect live peer state and routes, edit routing policies, and manage neighbors over SSH from one interface.

  • Live peer monitoring, state alerts, and transition history
  • Neighbor, route-map, prefix-list, and community-list editors
  • Configuration history with rollback support
  • Encrypted credentials and SSH connection multiplexing
